Display-restore probe

Verifies that getImageData → putImageData round-trip restores real pixels for visual display, while extracted bytes stay sanitized.

Requires the default thresholds: coarse=3, block=20. The page first spends the frame's budget on a scratch canvas, so the source canvas is read in block mode: the sanitized bytes are uniform gray and the display-restore is visually obvious. Each page load starts with a fresh budget; reload to re-run.
