Stability / consistency probe

Checks that every extraction path of one paint returns the same bytes (repeated reads, partial vs. full reads, raw pixels vs. PNG exports, toDataURL vs. toBlob) and that the fidelity chosen for a paint holds until the canvas is painted again. All tests must be PASS.

Requires the default thresholds: coarse=3, block=20. Each page load starts with a fresh budget; reload to re-run.
