Budget probe

Reads a canvas 30 times, repainting it before most reads, and observes the normal → coarse → block downgrade of the per-frame budget. The fidelity of a paint is decided by the budget at its first read and then holds for every further read of that paint, so reads 4-5 (no repaint after read 3) must still match read 3, and reads 21-22 (no repaint after read 20) must still match read 20.

Requires the default thresholds: coarse=3, block=20. Each page load starts with a fresh budget; reload to re-run. The source canvas is what the browser paints on screen (always unchanged); the other three show what scripts receive via extraction.
